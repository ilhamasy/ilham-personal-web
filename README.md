# Ilham Asyari — Personal Portfolio

Professional personal portfolio website built with Next.js, Tailwind CSS, and Node.js.

## Tech Stack

- **Frontend:** Next.js (React) + TypeScript
- **Styling:** Tailwind CSS v4
- **Backend:** Node.js (Next.js API routes)
- **Design:** Dark mode + orange accent + blurred blob background
- **No database required**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
├── app/            # Next.js App Router pages
├── assets/         # Static assets (images, CV, etc.)
├── components/     # Reusable UI components
├── public/         # Static files (favicon, manifest, icons)
└── ...
```

## Branching Strategy

- `development_master` — Main integration branch
- `feat/Story_XXX` — Feature branch per story

## Scripts

- `npm run dev` — Start development server
- `npm run build` — Build for production
- `npm run start` — Start production server
- `npm run lint` — Run ESLint
